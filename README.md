# Proyecto React Router Login

Proyecto sencillo en React con:

- Ruta `/login`
- Ruta protegida `/home`
- Ruta protegida `/about`
- Login usando `localStorage`
- Persistencia de sesión al recargar la página
- Cierre de sesión

## Cómo ejecutarlo

```bash
npm install
npm run dev
```

Luego abre la URL que aparece en la terminal.
